## Default Permission

Default permissions for the Connector plugin

#### This default permission set includes the following:

- `allow-push-dom`
- `allow-push-logs`
- `allow-set-pointed-element`
- `allow-push-ipc-event`
- `allow-push-capture-events`
- `allow-capture-self-test`
- `allow-push-event`
- `allow-push-runtime`
