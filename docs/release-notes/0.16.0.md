# v0.16.0

This release adds authenticated inspection to Tauri applications while preserving application-owned workflow deduplication, unknown-outcome quarantine, and the rule that dispatched writes are never automatically replayed.

- Active element selection starts a visible picker and returns reusable semantic locators, bounded metadata, optional native images, and independent selection, screenshot, and cleanup states. CLI, WebSocket, embedded MCP, and standalone MCP share the same application-owned picker.
- The document-scoped runtime uses instance/page identity, one verified installation, and small subsequent commands. Discovery can bind to the exact process and window; authenticated health probes distinguish transport, bridge, and page responsiveness.
- Shared semantic resolution covers accessible names, labels, roles, states, explicit unsupported tree boundaries, and stale-reference rejection.
- Protected native screenshots support WKWebView, WebView2, and WebKitGTK. Required masks precede encoding or output; source, geometry, fallback attempts, and context are reported explicitly. Artifact reads remain authenticated.
- Bounded IPC capture preserves original business results, exceptions, and promise behavior. Sessions expose pending calls, coverage, gaps, expiry, and drop counts; telemetry never clears workflow history or quarantine.

The [144-item acceptance report](https://github.com/dickwu/tauri-connector/blob/v0.16.0/docs/upgrade-implementation-status.md) distinguishes implementation, automated tests, native execution, and CI evidence for every requirement. Platform and fault scenarios without actual execution remain explicit verification gaps. See the [migration guide](https://github.com/dickwu/tauri-connector/blob/v0.16.0/docs/upgrade-migration.md) for the shared-token trust boundary, native screenshot feature flags, Windows private-journal restrictions, and immutable Tauri invoke interception coverage.

## Install

```sh
brew upgrade tauri-connector
# Or install the command-line packages directly:
cargo install connector-cli --version 0.16.0 --locked
cargo install connector-mcp-server --version 0.16.0 --locked
```

Update the host application's optional `tauri-plugin-connector` dependency to `0.16`, preserving its existing development feature gate. Installing a CLI alone does not update or restart other applications' embedded plugins.
