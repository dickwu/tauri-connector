# v0.17.3

This patch release fixes what a retest of 0.17.2 against a real Ant Design + Monaco app turned up. No new MCP tools or CLI commands. Unknown-outcome quarantine and the rule against replaying dispatched writes are unchanged.

## Bug fixes

- **Every command finds the app the way `status` does.** `windows`, `runtime-health`, `identity` and the other commands now share `status`'s discovery. A live `.connector.json` near the working directory routes every command once the endpoint proves it is that process, even when the app runs from another directory (e.g. `src-tauri`). From an unrelated directory the single verified app is selected and several give `ambiguous_app`. Explicit `--app-id`/`--app-instance-id`/`--pid-file` still never fall back. `runtime_health` reports a not-yet-installed runtime as `runtime_not_installed` and a loading page as `runtime_starting` with `retryAfterMs`, instead of `runtime_missing`.
- **`eval --timeout` reports a timeout, and statement scripts work.**
  - `eval` accepts an expression, a statement list (`const a = 1; a + 1` returns 2) or an async body with `return`/`await`.
  - A read-only script still pending at the deadline (no IPC, mutating fetch/XHR, beacon or WebSocket send observed) fails with `execution_timeout`, `effect: none` and nothing quarantined.
  - A script that may have dispatched effects is left running, so it reports `outcome_unknown` as before and a late result can still lift its quarantine.
- **Typing into Monaco works.** The editor is resolved from its container, hidden textarea or EditContext surface, and text is inserted line by line through `insertText` or EditContext updates. Targets that cannot take input report a reason.
- **Keys behave like a keyboard.** Synthetic keys carry `code`, `keyCode` and `which`, so `press Escape` closes Ant Design / rc-dialog modals (they check `keyCode === 27`). Combos and aliases are accepted, editing defaults (delete, undo, redo, select all) apply when the page does not prevent them, and an unknown key such as `press NotAKey` fails with `invalid_key` before dispatch, without quarantining.
- **CLI `fill` accepts CSS selectors.** `fill`, `type`, `press` and `drag` now go through the plugin's helpers (native value setter for React, editor-aware typing) instead of ad hoc eval scripts. `webview_keyboard` gains `selector` and a `fill` action.
- **Pointer drags hold the button.** Moves between down and up carry `buttons: 1`, so drag-to-reorder and sliders follow the pointer.
- **Console output stays readable and current.** Map and Set show their entries, DOM nodes print as `tag#id.class`, React elements as `<Name />`, and framework internals are never read. Objects are capped (depth 6, 50 entries per level, 16 KB per message). `logs` pulls pending entries from the page before reading, so `logs -p` no longer comes back empty, and the 500-entry buffer no longer stops advancing when full.
- **Screenshots.**
  - A full-window capture of a visible page that comes back as a single colour is retaken from the WebView's own redacted capture. The result reports `captureSource: "webview_native"` and `fallback: {from, to, reason: "uniform_image", outcome}`, and the CLI prints a `note:` line. The white screenshot seen with an Ant Design modal open could not be reproduced on the test fixture, so this fallback is the fix rather than a confirmed root cause.
  - The default window capture only considers the app's own windows. It used to take the first window from any process whose title matched.
  - `--source window_native` works on macOS. The window reported its title bar as part of the content area, so the size check failed with `geometry_unknown`. The title bar band is now cropped.
  - `--source dom_rendering` needs the app to expose snapdom as a global: add `import { snapdom } from '@zumer/snapdom'; window.snapdom = snapdom;` to the app entry. Installing `@zumer/snapdom` alone is not enough, because the protected capture pipeline never imports modules. Without it the error is now `capture_backend_unavailable` naming this fix (previously `execution_failed`).
- **`resources` lists each late result once.** A request that settles again refreshes its line, a settled outcome is never downgraded to `lost`, and identical lines from older plugins print once with an `(xN)` count.
- **Plain `snapshot` explains why it has no refs.** Only `snapshot -i` assigns `@eN` refs. Other modes now end with `No @eN refs: <mode> snapshots do not assign refs ...` instead of `0 refs captured`.

## Skill

- The bundled skill documents the eval timeout rules, the screenshot fallback and source requirements, the late-result history and the ref-less snapshot message.

## Install

```sh
brew upgrade tauri-connector
# Or install the command-line packages directly:
cargo install connector-cli --version 0.17.3 --locked
cargo install connector-mcp-server --version 0.17.3 --locked
```

Host applications on `tauri-plugin-connector = "0.17"` pick up the fixes with `cargo update -p tauri-plugin-connector`, then a rebuild and restart of the app. Installing a CLI alone does not update or restart other applications' embedded plugins.
