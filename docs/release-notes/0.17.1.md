# v0.17.1

This patch release fixes two bugs in 0.17.0. It adds no new tools. Unknown-outcome quarantine and the rule against replaying dispatched writes are unchanged.

## Bug fixes

- **A failed eval no longer locks the window until restart.** In 0.17.0, every `webview_execute_js` script that threw or rejected was treated as possibly effectful and quarantined its window. From then on, every eval and interaction returned `resource_busy` (`acquiring`, `not_dispatched`) until the app restarted, even when the script only threw a `TypeError`. The page now observes whether a script dispatched anything that can reach the backend while it ran: app IPC, a non-GET/HEAD/OPTIONS `fetch` or XHR, `sendBeacon`, or an app WebSocket send. If nothing was dispatched, the failure reports `execution_failed` with `effect: none` and releases the lease. Any observed dispatch, or a channel that cannot be observed, still reports `effect: possible` and quarantines the window as before. Work a script schedules to run after it rejects is not observed.
- **Read-only tool failures no longer quarantine.** A failed `webview_screenshot`, `webview_dom_snapshot`, `webview_find_element`, `webview_get_styles`, `webview_wait_for`, or `wait` (for example "Window not found") now reports `effect: none` and releases its lease. Failed interactions and other writes still quarantine.
- **Expired workflow budgets are timeouts, not cancellations.** A step or run budget that ran out just before dispatch was reported as `cancelled_before_dispatch`. It is now a failed step with `condition_timeout`, like every other deadline. Only an explicit cancel is reported as a cancellation.
- **Interrupted revalidation is no longer a resumable pause.** When the run deadline or a cancel cut a continuation's revalidation short, the run paused as `precondition_failed` and offered `continue`, which the expired deadline then rejected. Only a genuine precondition mismatch pauses that way now.

## Dependencies

- Picked up semver-compatible updates to `brotli`, `erased-serde`, `openssl-probe`, and `rustix`.

## Install

```sh
brew upgrade tauri-connector
# Or install the command-line packages directly:
cargo install connector-cli --version 0.17.1 --locked
cargo install connector-mcp-server --version 0.17.1 --locked
```

Host applications on `tauri-plugin-connector = "0.17"` pick up the fix with `cargo update -p tauri-plugin-connector`, then a rebuild and restart of the app. Installing a CLI alone does not update or restart other applications' embedded plugins.
