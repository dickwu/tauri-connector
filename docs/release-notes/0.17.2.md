# v0.17.2

This patch release fixes problems agents hit while driving apps with 0.17.1. It adds one MCP tool (`resources`), one CLI command (`tauri-connector resources`) and `eval --timeout`. Unknown-outcome quarantine and the rule against replaying dispatched writes are unchanged; there is now a way out of a quarantine other than restarting the app.

## Bug fixes

- **Tokenless debug hosts allow inspection again.** Without a host workflow token, discovery (`app_identity`), `status`, `runtime-health`, rich screenshots, the element picker and IPC capture work unauthenticated. Only `workflow_*` run/get/cancel/resume need the token. A token shorter than 32 bytes is ignored with a stderr warning, and `status` shows a token-protected instance as `unauthorized` instead of `stale`.
- **A timed-out eval no longer locks the window until restart.**
  - A timed-out `webview_execute_js` still reports `outcome_unknown` and quarantines its window. The connector now keeps listening for that request's page result for 10 minutes. A late success, or a late throw with `effect: none`, lifts the quarantine automatically and is recorded as a late settlement. A late failure with possible effects keeps it. While it waits, `bridge_status` reports the request under `awaitingLateResult`, not `pending`.
  - `resource_busy` now names the quarantining `requestId` and reason (`quarantines[]` in the outcome, and in the message).
  - New `tauri-connector resources` and MCP `resources` tool list quarantines and recent late results. `resources release <requestId>` or `--all` (MCP `action: "release"`) lifts a quarantine after you have checked the app. Active leases are never released.
  - `eval --timeout <ms>` (MCP `timeoutMs`, 1–600000, default 30000) sets the page deadline. The client waits 5 s longer, so the plugin's typed timeout with its `requestId` always arrives instead of a bare client timeout.
  - Empty eval scripts are rejected before anything is sent.
- **Failures before dispatch no longer quarantine.** A missing, disabled or stale target, missing arguments or an unknown action in `webview_interact`/`webview_keyboard` returns `not_dispatched` with `effect: none` and releases the lease.
- **Click behaves like a cursor.** `click` dispatches the full pointer/mouse sequence at the element's visual centre. When another element covers it, the result reports `mismatch: true`, the covering `hit` element and a warning. The `text` strategy picks the deepest element containing the text (visible matches first) instead of the first ancestor.
- **Typing into Monaco and contenteditable works.** `type` uses `insertText` for contenteditable hosts and Monaco editors (`method: "execCommand"`, `editor`); Monaco results carry `verified: false`. `fill` on Monaco returns `not_actionable` instead of a fake success.
- **`wait --text` matches what is on screen.** NBSP and whitespace runs are normalised, and the match also covers DOM text hidden from `innerText`, field values and same-origin iframes.
- **Snapshots of large pages stay usable.** Oversized sections split recursively, so one app-root wrapper no longer spills the whole page. Open overlays render inline first only when the page does not fit. Every ref, inline or spilled, is cached for `click`/`fill`. Containers such as `body`, `main` or a `form` are no longer `[redacted]` because they hold a password field.
- **Console logs read like devtools.** `%s %d %i %f %o %O` are substituted, `%c` styling is dropped, and `Error` arguments print their name, message and stack. CLI log lines show local time with the UTC offset.
- **Old plugins get a clear upgrade message instead of `app_not_found`.** Plugins before 0.16.0 cannot answer the identity handshake, so `--pid-file`, `--app-id` and `TAURI_CONNECTOR_PID_FILE` routing to them used to end in a generic `app_not_found`. Discovery now probes such an endpoint and returns `capability_unavailable` naming the port, the 0.16.0 minimum and the `--port <port>` workaround; `status` labels the instance `legacy_plugin` rather than `stale`. Identity is still never assumed: routing by app or PID file does not connect to an unverified endpoint. The `identity` error for these plugins now names the release that introduced inspection protocol v1.
- **Screenshots warn about hidden pages.** When the page reports `visibilityState: hidden`, or a full-window capture is a single colour, the screenshot carries `warnings: [{code: "page_hidden", ...}]` (the CLI also prints it to stderr). If every capture backend fails on a hidden page, the error ends with a `page_hidden` hint.

## Skill

- The bundled skill documents the `resources` command and tool, `eval --timeout`/`timeoutMs`, and the `page_hidden` warning. Bun fallback scripts gain `resources.ts` and `eval.ts --timeout`.

## Dependencies

- The TypeScript fallback packages (`cli/`, `server/`) moved to `ws` 8.22.0, `@modelcontextprotocol/sdk` 1.32.2, `zod` 4.6.7, `@types/node` 26.6.5, `@types/ws` 8.18.2 and `tsx` 4.23.15.

## Install

```sh
brew upgrade tauri-connector
# Or install the command-line packages directly:
cargo install connector-cli --version 0.17.2 --locked
cargo install connector-mcp-server --version 0.17.2 --locked
```

Host applications on `tauri-plugin-connector = "0.17"` pick up the fixes with `cargo update -p tauri-plugin-connector`, then a rebuild and restart of the app. Installing a CLI alone does not update or restart other applications' embedded plugins.
