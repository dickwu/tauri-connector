# 0.17.10

## Summary

Dependency refresh. No connector API, protocol, port or behavior changes: the 0.17.9 locked-screen and doctor fixes carry over unchanged. Upgrade at your convenience; Linux Wayland capture picks up the `xcap` 0.9.10 portal rewrite.

## Dependencies

`xcap` 0.9.10 replaces its direct `zbus` 5 use with `ashpd` 0.14 (zbus 6) for Wayland portal capture, which drops the old `async-io`/`async-executor`/`zvariant` 5 stack and several unused `objc2-*` feature crates from the lockfile. The new `dom_query` 0.29 / `html5ever` 0.40 / `selectors` 0.41 / `phf` 0.14 entries arrive with `wry` 0.57.2.

Unchanged on purpose: GTK-bound `gio`/`cairo-rs` stay on the 0.18 line that `webkit2gtk` 2.0 requires; `generic-array` 0.14.7 (`crypto-common` pins `=0.14.7`), `matchit` 0.8.4 (`axum` pins `=0.8.4`) and the `toml` 0.8.2 / `toml_datetime` 0.6.3 / `toml_edit` 0.20.2 stack (`proc-macro-crate` exact constraints) are held by upstream requirements; `encodeurl` 3.x is outside its parent's 2.x range. Root npm packages (Playwright 1.65.0, React 19.3.1) and the CLI/server direct packages were already latest. GitHub Actions pins were already on the latest releases; `dtolnay/rust-toolchain@stable` stays on its stable channel and CI stays on Node 22.

## Install / upgrade

```bash
brew update && brew upgrade tauri-connector
# or
cargo install connector-cli --version 0.17.10 --locked

# crates.io app (raise the manifest requirement first if pinned older):
cargo update --manifest-path src-tauri/Cargo.toml -p tauri-plugin-connector -p connector-client --precise 0.17.10
# git-main app: same command without --precise 0.17.10

npx skills add dickwu/tauri-connector
```

Rebuild and restart the host app; upgrading the CLI alone cannot replace an embedded plugin. Preserve existing fixed ports and feature gates. Apps that enable the plugin's `xcap` feature also move to `xcap` 0.9.10 (and, on Linux, `zbus` 6); review the lockfile diff.
